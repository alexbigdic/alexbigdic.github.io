1. 我们收集的信息

  • 设备与网络：稳定的匿名安装 ID（deviceId）、系统/应用版本、设备型号、语言与区域标签（含 en/es/pt-BR/zh-CN/de/fr/it 选择）、网络类型、IP 地址（服务端与 SDK 可见）及大致地区。
  • 广告标识符：Google 广告 ID（GAID/AAID）或等效设备级广告 ID，归因时可能使用。
  • 使用与内容：观看的剧集、观看进度与位置、解锁历史（unlockIndex）、已看集数/时长、完成的任务、每日签到日期与连续天数、加油包余额、钻石余额与 pendingDelta、首页/插屏/信息流广告曝光计数、评分使用时长、闪屏展示时间及广告互动。

  • 账户（如创建）：用户 ID、邮箱（如提供）、您分享的资料。现版本为匿名（无需邮箱）；“账户”数据在未来登录前即为匿名安装 ID。
  • 诊断：Firebase Crashlytics 崩溃堆栈、广告响应信息与付费事件价值 micros/精度/币种（AdValue、responseInfo、adSourceName）用于 ILRD，以及心跳事件队列载荷。
  • 推送：您允许通知时的 Firebase Cloud Messaging token，以及数据推送载荷（title/body/drama_id/start_ep）。
  • 归因与来源：延迟深链 URL、点击 ID、活动 ID、Play Install Referrer，以及经 Facebook 应用 ID 1431674870015167 的 Meta 安装来源。

2. 信息收集方式

我们通过以下方式收集信息：(a) 通过 SDK 与应用在设备上自动收集；(b) 您主动提供（如联系客服、创建账户）；(c) 通过第三方合作伙伴（分析、广告、归因、积分墙）；(d) 经 HMAC 签名的后端 API（正式为 https://hwdj.nqlian.com/，测试为测试域名，携带 X-Device-Id、X-Ts、X-Nonce、Rapid-Api v2.HMAC-SHA256 头）；(e) 通过 Google Play Billing 回调与 Play Install Referrer API；(f) 通过您与 UMP 同意表单的交互。

4. 信息使用方式

我们将数据用于：运营剧集目录与 ExoPlayer ViewPager2 播放器（3 播放器 LRU 池）；计算与追踪奖励（7 日签到状态机、看集/看时长/看广告任务、钻石账本 pendingDelta + 服务端快照、按集消耗的加油包额度）；通过 eCPM 瀑布流（control_ad）按位 TTL（SPLASH 4h、ITS/REWARD/PLAY_BACK 1h、FEED 30m）与信息流频次上限投放与衡量广告；应用首期订阅定价阶段并在服务端校验权益；尽力推送可跳转 zapreels://drama 的通知；检测欺诈（时钟防回拨、在途计费守卫）并保证 16 KB 页面兼容；改进体验、履行法定义务并回复支持。

5. 数据共享与披露

我们不出售您的个人信息。可能共享的情形包括：

  • 与 §3 所列 SDK 提供方按所述用途共享（例如向 AdMob/Pangle/Liftoff/InMobi 共享 GAID/IP 以竞价；向 Google Play 共享 deviceId/购买 token；向 Firebase/Tenjin/Adjust 共享 AdValue/responseInfo 用于 ILRD；向 Tapjoy/Unity 及其广告主共享积分墙数据）；
  • 与我们的后端 hwdj.nqlian.com 进行 HMAC 校验的 API 调用；
  • 按法律要求向执法/监管机构披露；
  • 在合并、收购或资产出售时进行转移；
  • 经您同意或按您指示共享。

Tapjoy 是积分墙金币的托管方；我们不在本地持有金币余额（仅通过 getCurrencyBalance 展示）。

6. 数据保留

使用/行为数据最长保留 24 个月。聚合匿名分析可能永久保留。本地 UserPrefs（deviceId、语言、钻石/加油包余额、任务/签到历史、首页插屏/信息流计数、评分使用）与 Room 表（history/favorite/ep_cache/event_queue，schema v3）在您清除数据/重装前持续保留；破坏性降级将清除。心跳 WorkManager（15 分钟）将重试 event_queue 直至上传。积分墙金币余额存于 Tapjoy 服务端。账户数据保留至您删除账户或请求删除；我们在验证请求后删除/匿名化，受限于法定保留义务。

7. 同意、隐私选择与 DMA

应用在首次启动时（按需）在适用地区展示 Google UMP 同意表单。Fail-closed：状态为 UNKNOWN 或 DENIED 时将抑制广告请求（ConsentGate.canRequestAds()）。Debug 构建以记录的覆盖将 UNKNOWN→NOT_REQUIRED 旁路。

当您授予/拒绝时，同意将分发至：

  • Pangle 经 PAGConsent，
  • Liftoff/Vungle 经 VunglePrivacySettings.setGDPRStatus/setCCPAStatus，
  • InMobi 经 InMobiPrivacyCompliance.setDoNotSell(!granted)，
  • Tapjoy 经 TJPrivacyPolicy setUSPrivacy / setBelowConsentAge / setUsageStatsConsent（subjectToGdpr 硬编码 true），
  • Tenjin 经 optIn/optOut 及 Google DMA setGoogleDMAParameters / optInGoogleDMA / optOutGoogleDMA（我们不调用 Tenjin 的 optInOutUsingCMP，否则在 TCF 为空时会覆盖我们 fail-closed 的 optOut）。

Tenjin 以 60 秒节流（setConnectInterval(60s)）连接，并在每次 onResume 重连；收入分通道上报：订阅经 subscription(Purchase, price, currency)（以末 pricing phase 即原价为准），一次性内购经 transaction——iap_purchase 事件不带收入以防双计。

您可通过重新展示 UMP 表单（应用内设置可用时）或系统设置撤回同意；也可重置 GAID、开启“选择停用广告个性化”、在“设置 → 推送”或系统通知设置中关闭推送，以及对积分墙 withheld 同意（“赚金币”按钮在未连接时仅提示加载中）。

8. 儿童隐私

本应用不面向 13 岁以下儿童，亦不会有意收集其数据。我们通过 setTagForUnderAgeOfConsent(false) 标记请求，并在同意前采取 fail-closed 措施避免展示个性化广告。若发现 13 岁以下儿童提供了个人信息，我们将删除。欧盟 16 岁以下用户请在监护人同意下使用。

9. 您的权利

根据您所在司法辖区（欧盟 GDPR、英国 GDPR、巴西 LGPD、美国 CCPA/CPRA 等），您可能享有：访问我们持有的个人数据；更正不准确数据；删除数据；限制或反对处理；以可携格式接收数据；在基于同意的处理中撤回同意；以及选择退出出售/共享（我们不出售；InMobi setDoNotSell 尊重您的退出）。行使权利请联系 privacy@zapreels.app，我们将在适用法律要求的时限内回应。

10. 数据安全

我们采取合理的技术与组织措施：usesCleartextTraffic=false + network_security_config、HMAC-SHA256 请求签名（Rapid-Api: v2.<hex>）、allowBackup=false、R8 全量混淆 + 资源压缩、16 KB 页面对齐，以及用于离线法务文档的 WebView 加固（javaScriptEnabled=false、allowFileAccess=false）。没有任何方法能保证 100% 安全。

11. 跨境数据传输

您的数据可能被传输并在您居住国以外的国家处理，包括美国及 Google、Adjust、Tenjin、Pangle、Liftoff、InMobi、Tapjoy/Unity 运营的其他地区。按要求时，传输依赖标准合同条款或充分性认定。

12. 政策变更

我们可能不时更新本政策。我们将在应用内发布更新后的政策并更新上方的“最后更新”日期。您在生效后继续使用即表示接受。
